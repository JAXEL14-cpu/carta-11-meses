# Carta digital — 11 meses contigo

Sitio estático hecho con HTML, CSS y JavaScript. Las imágenes usan rutas relativas en `imagenes/`; no requiere build ni backend.

## Publicar con GitHub Pages

1. Entra en [github.com](https://github.com/) e inicia sesión o crea una cuenta.
2. Pulsa **+** arriba a la derecha → **New repository**.
3. Ponle un nombre, por ejemplo `carta-11-meses`; elige **Public** y pulsa **Create repository**.
4. En el repositorio, pulsa **Add file** → **Upload files**.
5. Arrastra los archivos `index.html`, `style.css`, `script.js`, `.nojekyll`, `README.md` y la carpeta `imagenes` completa. Si agregas `musica.mp3`, súbelo también. Confirma con **Commit changes**.
6. Abre **Settings** → **Pages**. En **Build and deployment**, en **Source** selecciona **Deploy from a branch**; elige **main** y **/(root)**; pulsa **Save**.
7. Espera a que Pages termine la publicación. La dirección aparecerá en **Settings → Pages** y tendrá la forma `https://TU-USUARIO.github.io/carta-11-meses/`.

El repositorio público permite que GitHub Pages sirva el HTML y todas las fotos. Cualquiera que tenga acceso al repositorio puede ver sus archivos. No incluyas información que quieras mantener privada.

## Fotos y canción

Las ocho fotos están en `imagenes/foto1.jpg` a `foto8.jpg`. Para cambiarlas, reemplaza esos archivos conservando los nombres. Para añadir la canción, copia `musica.mp3` en la raíz junto a `index.html`; se reproduce cuando se toca el botón y el navegador lo permite.
